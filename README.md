# translateDocs
docs 파일 문서 영문 변환. selenium과 papago api 이용

papago api 일일 한도로 인해 번역량이 많은 경우 제약이 생기는 문제 <br>
-> selenium을 이용해 번역하는 과정을 자동화 하여 api호출 제한 없이 번역가능
